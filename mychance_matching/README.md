# mychance_matching (legado)

Protótipo original do algoritmo de matching em Python, usado nas sprints iniciais do projeto.

A versão em produção está no repositório **mychance-NLP**, exposta via FastAPI. Este diretório permanece apenas como referência.

Para executar os testes locais deste módulo:

```bash
pip install -r requirements.txt
pytest tests/ -v
```
